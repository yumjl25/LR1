# Лабораторная работа №1: Абстрактные структуры данных

Консольная программа на **C++**, которая реализует базовые абстрактные структуры данных и позволяет работать с ними через текстовые команды. Данные читаются из файла и записываются обратно при каждом изменении.

## Реализованные структуры

| Структура | Префикс команд | Особенности реализации |
|---|---|---|
| Массив | `M` | динамический, capacity удваивается при заполнении |
| Односвязный список | `F` | указатели `head` и `tail`, счетчик `size` |
| Двусвязный список | `L` | указатели `head` и `tail`, у узла есть `prev` и `next` |
| Очередь | `Q` | на связных узлах, FIFO |
| Стек | `S` | на связных узлах, LIFO |
| Дерево | `T` | АВЛ-дерево (сбалансированное двоичное дерево поиска) |

## Сборка

```bash
g++ -std=c++17 -o dbms_cpp *.cpp
```

## Запуск

```bash
./dbms_cpp --file file.data --query '<КОМАНДА>'
```

- `--file` файл, в котором хранятся данные
- `--query` команда, которую нужно выполнить

Пример:

```bash
./dbms_cpp --file file.data --query 'SPUSH mystack item'
```

## Команды

| Тип контейнера | Добавление | Удаление | Чтение |
|---|---|---|---|
| Массив (M) | `MPUSH` | `MDEL` | `MGET` |
| Односвязный список (F) | `FPUSH` | `FDEL` | `FGET` |
| Двусвязный список (L) | `LPUSH` | `LDEL` | `LGET` |
| Очередь (Q) | `QPUSH` | `QPOP` | `QPOP` |
| Стек (S) | `SPUSH` | `SPOP` | `SPOP` |
| Дерево (T) | `TINSERT` | `TDEL` | `TGET` |

Дополнительные команды для массива: `MLEN` (длина), `MSET` (замена элемента по индексу).
Команда `PRINT <имя>` выводит содержимое любой структуры на экран.

## Пример работы (массив)

```bash
./dbms_cpp --file file.data --query 'MPUSH myarray 5'      # -> 5
./dbms_cpp --file file.data --query 'MPUSH myarray 6'      # -> 6
./dbms_cpp --file file.data --query 'MPUSH myarray 7'      # -> 7
./dbms_cpp --file file.data --query 'MPUSH myarray 99 1'   # -> 99   (вставка по индексу 1)
./dbms_cpp --file file.data --query 'MLEN myarray'         # -> 4
./dbms_cpp --file file.data --query 'MGET myarray 2'       # -> 6
./dbms_cpp --file file.data --query 'MSET myarray 0 100'   # -> 100
./dbms_cpp --file file.data --query 'MDEL myarray 2'       # -> 6
./dbms_cpp --file file.data --query 'PRINT myarray'
```

Вывод последней команды:

```
ARRAY:
  [0] 100
  [1] 99
  [2] 7
```

## Временная сложность

`n` это число элементов в структуре.

| Структура | Добавление | Удаление | Чтение / поиск |
|---|---|---|---|
| Массив | O(1) амортиз. в конец, O(n) по индексу | O(n) | O(1) по индексу |
| Односвязный список | O(1) в голову и хвост, O(n) до/после элемента | O(1) голова, O(n) хвост, до/после, по значению | O(1) голова и хвост, O(n) по индексу и поиск |
| Двусвязный список | O(1) в голову и хвост, O(n) до/после элемента | O(1) голова и хвост, O(n) до/после, по значению | O(1) голова и хвост, O(n) по индексу и поиск |
| Очередь | O(1) | O(1) | O(1) |
| Стек | O(1) | O(1) | O(1) |
| АВЛ-дерево | O(log n) | O(log n) | O(log n) |

Подробное обоснование каждой операции приведено в отчете.
